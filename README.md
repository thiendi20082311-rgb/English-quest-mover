# English Quest Movers

Slice 0 xây một vòng học hoàn chỉnh cho Unit 1 **At the park**: từ vựng, ngữ pháp, quiz, điểm và tiến trình.

## Chạy trên máy

1. Cài dependencies bằng `pnpm install`.
2. Sao chép `.env.example` thành `.env.local` và điền cấu hình Supabase.
3. Chạy `pnpm dev`.

## Kiểm tra

- `pnpm lint`
- `pnpm build`

Đọc `SPEC.md` trước khi thay đổi tính năng. Mọi thay đổi schema phải được Owner duyệt và ghi vào `docs/DECISIONS.md`.
